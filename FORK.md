# LxBox Legacy — форк для старых и слабых устройств

Форк [Leadaxe/LxBox](https://github.com/Leadaxe/LxBox) с поддержкой
Android 4.2+ (API 17).

| Ветка | Android | Flutter / Dart | Ядро |
|---|---|---|---|
| `main` | 7.0+ (API 24) | 3.47.1 / 3.11 | `libbox` 1.14.2-lx.11 (оригинальный) |
| `legacy-api17` | **4.2+ (API 17)** | **3.13.9 / 3.1.5** | `libbox` 1.14.2-lx.11, пересобранный под API 17 |

Новые функции есть в обеих ветках.

## Новые функции

**Стили интерфейса** — Настройки → «Внешний вид» → «Стиль интерфейса»:

| Стиль | Основа |
|---|---|
| Material Design 3 | исходный вид LxBox (по умолчанию на Android 5.0+) |
| Material Design 1 | спецификация Material Design 2014: Indigo 500 / Pink A200, типографика 2014, тени, углы 2dp, волна InkRipple |
| Holo | Android Design 4.x: Holo Blue `#33B5E5`, тёмная панель действий, плоские поверхности, подсветка нажатия без волны (по умолчанию на Android 4.x) |

**Упрощённые анимации** (там же, по умолчанию включены): мгновенные переходы
между экранами, без анимации смены темы, без шейдерной «искры» нажатия, без
вращающегося значка подключения.

**Рисовать на CPU** (там же): программный рендеринг Skia вместо OpenGL ES —
для устройств, чей GPU-драйвер не справляется. На Android 4.x в лаунчере есть
отдельный значок **«L×Box (CPU)»**: он запускает приложение сразу с
программным рендерингом (если обычный запуск показывает пустой экран).

**Маршрутизация сайтов** — Маршрутизация → вкладка «Сайты» (как в Amnezia VPN):
режимы «Выключено» / «Белый список» / «Чёрный список»; домены (с поддоменами),
IP и подсети; импорт/экспорт в формате Amnezia VPN (`[{"hostname", "ip"}]`) и
импорт простого текста. Работает внутри ядра, поэтому действует и в режиме
прокси; входит в бэкап.

**Импорт `.conf`** — WireGuard / AmneziaWG (включая поля AWG 2.0) через
«Серверы → Импорт из файла» — поддерживался исходным LxBox.

## Android 4.x (ветка `legacy-api17`)

**Ядро.** `sing-box-lx` собран gomobile с `-androidapi 17` и NDK r23c; два
патча старых ядер Linux (локальная ветка `lx-legacy` форка ядра):
- i386: отправка пакетов через `socketcall(2)` — прямой `sendmsg` есть в ядре
  i386 только с Linux 4.3 (без патча Hysteria/Hysteria2 с обфускацией не
  работали бы на x86);
- отказ `SO_REUSEPORT` (Linux 3.9+) не фатален.

Требование Go «ядро Linux ≥ 3.2» — политика поддержки, не проверка при
запуске: рантайм Go 1.25 на ядрах 3.0/3.4 обходится запасными путями.

**Что работает иначе, чем на Android 5.0+:**
- «Приложения в туннеле» — правилами ядра `package_name` (у VpnService нет
  per-app API): исключённые приложения проходят через туннель, но идут
  напрямую, минуя VPN-сервер;
- QR-сканер скрыт (плагин камеры требует Android 5.0);
- нет плитки быстрых настроек (Android 7.0+) и ярлыков (7.1+);
- корневые сертификаты: Android до 7.1.1 не знает ISRG Root X1 (Let's Encrypt),
  поэтому загрузка подписок использует встроенный набор Mozilla
  (`assets/certs/cacert.pem`), а ядро — `certificate.store: mozilla`;
- сеть отслеживается через `CONNECTIVITY_ACTION` и `/proc/net/route`.

**Проверено:**
- ядро (`sing-box`, `libbox.so`) загружается и работает на эмуляторе Android
  4.2.2: DNS, TCP, TLS; патч `sendmsg` подтверждён на ядре 3.10;
- приложение стартует на эмуляторе Android 4.2.2: Kotlin-хост, плагины,
  Dart-логика, контроллеры, связь с ядром (по логам);
- **интерфейс на эмуляторе Android 4.2 не отображается** — это ограничение
  старого образа эмулятора: так же не рисуется пустой проект `flutter create`.
  Внешний вид нужно проверять на реальном устройстве.

## Сборка

```
# ветка legacy-api17, Flutter 3.13.9
flutter build apk --release --target-platform android-arm
```

Нужны: `app/android/app/libs/libbox-api17.aar` (ядро под API 17), JDK 17+
(Gradle 8.5 запускается и на JDK 21). Без `key.properties` APK подписывается
отладочным ключом.
