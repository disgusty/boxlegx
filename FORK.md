# LxBox Legacy — форк для старых и слабых устройств

Форк [Leadaxe/LxBox](https://github.com/Leadaxe/LxBox). Цель — поддержка
Android 4.2+ (API 17). Работа идёт по этапам.

## Этап 1 — новые функции (сделано, текущая кодовая база, API 24+)

**Стили интерфейса** — App Settings → «Внешний вид» → «Стиль интерфейса»:

| Стиль | Основа |
|---|---|
| Material Design 3 (по умолчанию) | исходный вид LxBox |
| Material Design 1 | спецификация Material Design 2014: Indigo 500 / Pink A200, типографика 2014, тени, углы 2dp, волна InkRipple |
| Holo | Android Design 4.x (ICS/JB): Holo Blue `#33B5E5`, тёмная панель действий, плоские поверхности, подсветка нажатия без волны, табы с голубым индикатором |

Код: `app/lib/theme/app_style.dart` (состояние, SharedPreferences),
`app/lib/theme/app_themes.dart` (темы). Светлая/тёмная тема работает во всех стилях.

**Упрощённые анимации** — там же, переключатель (по умолчанию ВКЛ):
мгновенные переходы между экранами, без смены темы с анимацией, без шейдерной
«искры» нажатия (InkSparkle → InkRipple), без вращения значка подключения,
подсветки списков без анимации.

**Маршрутизация сайтов** — Маршрутизация → вкладка «Сайты», аналог
split-tunneling по сайтам в Amnezia VPN:

- режимы «Выключено» / «Белый список» (только эти сайты через VPN) /
  «Чёрный список» (эти сайты мимо VPN) — как у вкладки приложений;
- домены (с поддоменами), IP и подсети CIDR; ввод URL нормализуется;
- импорт/экспорт списка в формате Amnezia VPN (`[{"hostname", "ip"}]`),
  импорт простого текста (по сайту в строке);
- работает внутри ядра sing-box (route-правило сразу после sniff/hijack-dns),
  поэтому действует и в режиме прокси; входит в бэкап (категория «Маршрутизация»).

Код: `app/lib/screens/route_sites_tab.dart`,
`app/lib/services/settings_storage/route_sites.dart`,
`app/lib/services/builder/post_steps/route_sites.dart`,
тесты — `app/test/builder/route_sites_test.dart`.

**Импорт `.conf`** — WireGuard / AmneziaWG (включая поля AWG 2.0: `Jc/Jmin/Jmax`,
`S1–S4`, `H1–H4`, `I1–I5`) импортируется через «Серверы → Импорт из файла»;
это уже поддерживалось исходным LxBox, изменений не потребовалось.

## Этап 2 — Android 4.2 (API 17) (не начат)

Препятствия и план:

1. Flutter 3.47 требует API 24; последний Flutter с API 16–18 — 3.16
   (Dart 3.2). Нужен перенос кода (142 тыс. строк) и замена плагинов.
2. Ядро `sing-box-lx` (Go 1.25.5) — пересборка libbox с NDK r23c под API 17.
   Требование Go «ядро Linux ≥ 3.2» — политика поддержки, а не проверка при
   запуске; системные вызовы новее имеют запасные пути. Устройства с ядром 3.4
   соответствуют, 3.0 — нужна проверка на устройстве.
3. Раздельное туннелирование приложений через VpnService (API 21+) на 4.x
   недоступно — заменяется правилами ядра.
4. Корневые сертификаты 4.x не содержат ISRG Root X1 — нужен встроенный набор CA.
